# Project Blueprint

## Overview

This document outlines the structure and features of the Strategy Game application. The app is built with Flutter and utilizes the go_router package for navigation.

## Implemented Features

*   **Navigation:** A side navigation rail allows users to switch between different sections of the app.
*   **Screens:** The following screens have been created:
    *   Login
    *   Playing
    *   Set Availability
    *   Captain
    *   Pending Invites
    *   Challenges
    *   Following
